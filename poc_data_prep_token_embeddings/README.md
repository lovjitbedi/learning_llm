## PoC: Data Prep and Token Embeddings

This proof of concept covers the end-to-end flow for preparing textual data and generating token embeddings for downstream usage.

### Summary
- **Reads a small dataset (text files).**
- **Tokenizes into a vocabulary.**
- **Converts tokens → token IDs.**
- **Generates embeddings (absolute + positional).**
- **Stores embeddings and retrieves them for usage.**
